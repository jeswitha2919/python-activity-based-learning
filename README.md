# README – Python Case Studies

## Introduction
This project contains 10 Python case studies designed to solve real-world problems using basic programming concepts.

## Topics Covered
1. University Scholarship Allocation
2. Progressive Electricity Billing
3. Hospital Billing and Patient Classification
4. Employee Payroll and Deduction Analysis
5. Telecommunications Cost Optimization
6. Railway Fare and Reservation Calculator
7. Retail Billing with Discounts
8. Manufacturing Cost and Profitability Analysis
9. Multi-Currency Travel Budget Analysis
10. Campus Event Financial Planning

## Concepts Used
- Algorithms and flowcharts
- Pseudocode
- Variables and data types
- Conditional statements
- Loops and lists
- Arithmetic calculations
- Python programming

## Requirements
- Python 3.x
- Any Python editor or IDE

## Conclusion
These case studies improve problem-solving and logical-thinking skills by applying Python programming to practical situations.
